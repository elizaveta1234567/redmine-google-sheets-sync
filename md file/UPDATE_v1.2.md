## 🎯 Режимы синхронизации

### Режим 1: Один раз (по умолчанию)
```
Выберите режим (1-3): 1
✓ Режим: Одноразовая синхронизация
[Синхронизирует один раз и выходит]
```

**Когда использовать:**
- Нужна быстрая ручная синхронизация
- Запуск по расписанию через Windows Task Scheduler
- Разовая проверка/обновление

---

### Режим 2: Каждые 5 минут
```
Выберите режим (1-3): 2
✓ Режим: Постоянное обновление каждые 5 минут
[Синхронизирует постоянно]
```

**Когда использовать:**
- Нужна почти реальная синхронизация
- Таблица всегда актуальна
- Оставляешь скрипт запущенным целый день

**Как остановить:** Нажми `Ctrl+C` в консоли

---

### Режим 3: Свой интервал
```
Выберите режим (1-3): 3
Введите интервал обновления (в минутах): 10
✓ Режим: Постоянное обновление каждые 10 минут
[Синхронизирует каждые 10 минут]
```

**Когда использовать:**
- Проект очень активный → каждую минуту
- Проект спокойный → каждые 30-60 минут
- Нужна точная настройка под твой ритм работы

## 💻 Использование с Windows

### Вариант 1: Запуск через батник (простой)
```
start_sync.bat
```

Батник теперь информативнее:
1. Показывает описание режимов
2. После завершения показывает статус
3. Ждёт нажатия любой клавиши

### Вариант 2: Windows Task Scheduler (автоматический)
Если нужна **автоматическая синхронизация без батника**:

1. Открыть Task Scheduler
2. Создать задачу "Redmine Sync"
3. Триггер: "При запуске" или "Каждый день в 9:00"
4. Действие: `python.exe` с параметром `sync_unified.py`
5. Сохранить

Но рекомендуется **Режим 2 или 3 в батнике** — проще и проверяет постоянно!

### Вариант 3: Запуск с параметром (продвинутый)
```
REM В будущих версиях (v1.3+) можно будет:
python sync_unified.py --mode periodic --interval 5
```

Пока не реализовано, но можно добавить в v1.3.

## 🔧 Техника: Как работает периодическое обновление

### Основной цикл:
```python
while True:
    sync_count += 1
    print(f"⏳ Синхронизация #{sync_count}")
    
    # Загружаем задачи и синхронизируем
    issues = fetch_issues(...)
    sync_to_google_sheets(...)
    
    # Ждём перед следующей синхронизацией
    print(f"💤 Следующее обновление через {interval_minutes} минут")
    time.sleep(interval_minutes * 60)
```

### Обработка ошибок:
- Если произошла ошибка при синхронизации → скрипт **не прерывается**
- Выводит ошибку в консоль
- Продолжает ждать перед следующей попыткой
- Это гарантирует, что скрипт не зависнет

### Остановка:
- Нажми `Ctrl+C` в консоли
- Скрипт выведет статистику (количество синхронизаций)
- Завершится корректно
