# Что произошло: Миграция на Unified Sync v1.0

## 🎯 Основное изменение

**Было:**
- Два отдельных проекта в папках
- Жестко закодированные параметры в каждом скрипте
- Нужно было дублировать код для каждого нового проекта

**Стало:**
- Один универсальный скрипт `sync_unified.py`
- Интерактивный ввод всех параметров
- Поддерживает **любой** проект и **любую** версию

## 📁 Новая структура

### Главные файлы (в корне проекта):
```
sync_unified.py              ← ЭТО ИСПОЛЬЗУЙ! Основной скрипт
redmine_client.py            ← Библиотека для работы с Redmine API
requirements.txt             ← Зависимости
start_sync.bat               ← Быстрый запуск (Windows)
service_account.json         ← Твой Google Service Account (⚠️ не грузить!)
```

### Старые папки (для справки):
```
redmine_google_sheets_nitro_rush_060/    ← Архив, больше не используется
redmine_google_sheets_sinstreets_051/    ← Архив, больше не используется
```

## ✨ Новые возможности

### 1. Один скрипт для всех проектов
```bash
# Старый способ:
cd redmine_google_sheets_nitro_rush_060
python redmine_export_google_sheets.py

# Новый способ:
python sync_unified.py
# → Выбираешь проект, версию, таблицу → ✅ готово!
```

### 2. Интерактивный выбор версий
```
Доступные варианты:
  1. [15] 0.6.0 (пуши, улучшения, награды)
  2. [16] 0.6.1 iOS
  3. [17] 0.6.2 Android

Выбор: 1,2  ← Выберешь нужные версии
```

### 3. Поддержка любых проектов
Старые скрипты были жестко привязаны к одному проекту:
- Nitro Rush 0.6.0
- Sin Streets 0.5.1

Теперь поддерживаются **все** проекты, которые есть в твоём Redmine!

### 4. Гибкость с Google Sheets
Один раз настроил параметры Redmine, можешь синхронизировать в разные таблицы:

```bash
# Запуск 1: Nitro Rush → Таблица А
python sync_unified.py
# (выбираешь версию 0.6.0, указываешь table_A_id)

# Запуск 2: Nitro Rush 0.6.1 → Таблица Б  
python sync_unified.py
# (выбираешь версию 0.6.1, указываешь table_b_id)
```

## 🔄 Как перейти на новый скрипт?

### Шаг 1: Убедись, что всё установлено
```bash
pip install -r requirements.txt
```

### Шаг 2: Положи `service_account.json` в корень
```
d:/Project/redmine-google-sheets-sync/
├── service_account.json    ← Положи сюда
├── sync_unified.py
└── ...
```

### Шаг 3: Запусти скрипт
```bash
python sync_unified.py
```

### Шаг 4: Следуй интерактивным подсказкам
- Введи URL Redmine (или нажми Enter для значения по умолчанию)
- Введи API ключ
- Выбери проект
- Выбери версии (или нажми Enter для всех)
- Введи Google Sheets ID
- ✅ Готово!

## ❓ FAQ

**Q: Могу ли я удалить старые папки?**
A: Да! Старые скрипты больше не нужны. Но оставь их если нужна справка по старому коду.

**Q: Что если мне нужны разные параметры для каждого проекта?**
A: Просто запусти скрипт несколько раз! Каждый раз выбираешь нужные параметры.

**Q: Можно ли сохранять конфигурацию?**
A: Сейчас нет, но это можно добавить. Скрипт просит параметры каждый раз для большей гибкости.

**Q: Что делать если забыл API ключ?**
A: Найди в Redmine: My account → API access key

**Q: Работает ли на Mac/Linux?**
A: Да! Скрипт на чистом Python. Используй `python sync_unified.py` вместо `start_sync.bat`
