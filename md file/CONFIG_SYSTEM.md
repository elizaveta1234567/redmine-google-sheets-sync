### Сценарий 2: Обновить конфиг для проекта

```bash
python sync_unified.py
→ Выбираю "Nitro Rush"
```

Или:

```bash

→ Ввожу новый ID (Table C)
✅ Конфиг обновлён
```

## ⚙️ Опции при использовании конфига

### Когда найден сохранённый конфиг:

1. **Использовать сохранённый** (нажми Enter или 'y')
   - Синхронизирует в ту же таблицу что и раньше
   - Быстро! Никакого ввода не требуется

2. **Не использовать, ввести новый** (нажми 'n')
   - Введёшь новый Google Sheets ID
   - Спросит обновить ли конфиг для этого проекта

3. **Обновить конфиг** (при использовании сохранённого)
   - Введёшь новый Google Sheets ID
   - Конфиг обновится

## 🔐 Безопасность

- ✅ `config.json` защищен в `.gitignore` (не будет грузиться в git)
- ✅ Сохраняются только ID таблиц и номер вкладки
- ✅ API ключи НЕ сохраняются (вводятся каждый раз)
- ⚠️ Если кто-то получит `config.json`, он может видеть какие таблицы ты используешь, но не сможет ничего изменить без API ключа

## 🆘 Решение проблем

**Q: Где находится config.json?**
A: В корне папки проекта рядом с `sync_unified.py`

**Q: Могу ли я вручную отредактировать config.json?**
A: Да! Просто отредактируй JSON и сохрани файл

**Q: Что если я удалю config.json?**
A: Скрипт создаст его заново при следующем запуске

**Q: Как удалить конфиг для проекта?**
A: Отредактируй `config.json` и удали нужный проект, или просто сохрани новый конфиг

**Q: Работает ли это на всех проектах?**
A: Да! Система автоматически сохраняет конфиг для каждого нового проекта
