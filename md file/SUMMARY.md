## 🚀 Как начать работу

### Вариант 1 (Быстро на Windows)
```bash
1. Положи service_account.json в корень папки
2. Двойной клик на start_sync.bat
3. Следуй подсказкам
```

### Вариант 2 (На любой ОС)
```bash
1. pip install -r requirements.txt
2. Положи service_account.json в корень папки
3. python sync_unified.py
4. Следуй подсказкам
```

## 📞 Частые вопросы

**Q: Могу ли я удалить старые папки?**
A: Да! Они больше не нужны:
- ❌ `redmine_google_sheets_nitro_rush_060/` — можно удалить
- ❌ `redmine_google_sheets_sinstreets_051/` — можно удалить

**Q: Что если я запущу скрипт дважды?**
A: Ничего страшного! Новые данные перезапишут старые. Просто запусти снова.

**Q: Могу ли я синхронизировать в разные таблицы?**
A: Да! Просто запусти скрипт несколько раз и указывай разные Google Sheets ID.

**Q: Работает ли на Mac/Linux?**
A: Да! Скрипт на чистом Python. Используй `python sync_unified.py`

**Q: Как часто запускать?**
A: Когда нужны свежие данные. Можно вручную или через Task Scheduler.
