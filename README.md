# Redmine → Google Sheets Sync

Локальный Python-скрипт для автоматической синхронизации задач из Redmine в Google Sheets.

✨ **v1.1 — Config System**: Сохраняет конфиг для каждого проекта! Просто выбираешь проект, и он автоматически синхронизируется в нужную таблицу.

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Подготовка Google Service Account

1. Создай JSON-ключ Google Service Account
2. Положи файл рядом со скриптом и переименуй в `service_account.json`
3. Поделись Google Sheets с email из `service_account.json`

### 3. Запуск

**Windows:**
```bash
start_sync.bat
```

**Или напрямую через Python:**
```bash
python sync_unified.py
```

### 4. Интерактивный процесс (Первый раз)

Скрипт запросит тебя по очереди:

```
1️⃣  Redmine URL (по умолчанию: https://redmine.justmoby.com/)
2️⃣  Redmine API ключ (найди в своем профиле: My account → API access key)
3️⃣  Выбери проект из списка
4️⃣  Выбери версию(и) (или пропусти для всех версий)
5️⃣  Введи Google Sheets ID или URL
6️⃣  Сохранить конфиг? (да/нет) — выбери "да" чтобы в следующий раз скрипт автоматически использовал эту таблицу
7️⃣  ✅ Синхронизация начнется!
```

### 5. Интерактивный процесс (Следующие разы)

Если ты сохранил конфиг, всё будет ещё проще:

```
1️⃣  Redmine URL (по умолчанию: https://redmine.justmoby.com/)
2️⃣  Redmine API ключ
3️⃣  Выбери проект из списка
4️⃣  ✓ Найден сохранённый конфиг для проекта
    Использовать сохранённый? (да/нет)
    → Нажми Enter (по умолчанию "да")
5️⃣  ✅ Синхронизация начнется в ту же таблицу!
```

## Как это работает

Скрипт запускается локально на компьютере и работает по схеме:

`Redmine API → Python → Google Sheets API`

Нейросеть/LLM не используется, токены не расходуются.

При каждом запуске скрипт:

1. Подключается к Redmine;
2. Получает список проектов;
3. Вы выбираете проект;
4. Получает все версии проекта;
5. Вы выбираете версию(и) для синхронизации (опционально);
6. Получает все задачи выбранного проекта/версии;
7. Оставляет только задачи с трекером `Ошибка`;
8. Перечитывает актуальные данные каждой задачи;
9. **Автоматически находит сохранённый Google Sheets для этого проекта** ⭐ (новое!)
10. Обновляет Google Sheets.

Обновляются не только новые задачи, но и изменения в существующих:

- название;
- ссылка;
- статус;
- комментарий;
- версия;
- приоритет;
- назначенный исполнитель.

## 🎯 Config System — Сохранение конфигов проектов

**Новое в v1.1!** Скрипт автоматически сохраняет конфиг для каждого проекта.

### Как это экономит время:

**Первый запуск (Nitro Rush):**
```
→ Ввожу Google Sheets ID для Nitro Rush
→ Нажимаю "Сохранить конфиг? (y/n)" → y
✅ Конфиг сохранён
```

**Второй запуск (Sin Streets):**
```
→ Ввожу Google Sheets ID для Sin Streets
→ Нажимаю "Сохранить конфиг? (y/n)" → y
✅ Конфиг сохранён
```

**Третий запуск (Nitro Rush снова):**
```
→ Выбираю "Nitro Rush"
→ ✓ Найден сохранённый конфиг!
→ Использовать? (y/n) → Enter
✅ Синхронизируется в ту же таблицу автоматически!
```

**Результат:** После первого использования каждого проекта, все следующие запуски — это просто выбор проекта и Enter!

### 📖 Подробнее

Читай [CONFIG_SYSTEM.md](CONFIG_SYSTEM.md) для полной информации о системе конфигов.

## Сортировка в Google Sheets

Задачи автоматически упорядочиваются так:

1. Срочный / Немедленный
2. Высокий
3. Нормальный
4. Низкий
5. Очень низкий
6. Бэклог
7. Решена / закрытые задачи

Таким образом, активные приоритетные баги остаются наверху, бэклог находится ближе к низу, а решённые задачи не мешают работе с актуальными багами.

## API Ключ

Найди свой API ключ в Redmine:
- Войди в свой аккаунт
- Перейди в `My account` → `API access key`
- Скопируй ключ

## Требования

- Windows
- Python 3
- доступ к Redmine API
- Google Service Account с доступом к нужной Google-таблице

Установка зависимостей внутри нужной папки проекта:

```bash
pip install -r requirements.txt
```

## Секреты и доступы

В репозитории намеренно **не хранятся**:

- `service_account.json`
- Redmine API key
- локальные `.env`
- логи
- `__pycache__`

Redmine API key берётся из переменной среды Windows:

```text
REDMINE_API_KEY
```

Проверить, что переменная доступна:

```bash
python -c "import os; print('OK' if os.getenv('REDMINE_API_KEY') else 'NO KEY')"
```

Для Google Sheets нужно положить рабочий файл:

```text
service_account.json
```

рядом со скриптом соответствующего проекта. Этот файл исключён через `.gitignore` и не должен попадать в GitHub.

Сервисному аккаунту также нужно выдать права **Редактор** на целевую Google-таблицу.

## Ручной запуск

Из папки нужного проекта:

```bash
python -X utf8 redmine_export_google_sheets.py
```

Либо использовать:

```text
start_google_sheets.bat
```

## Автоматический запуск

Для фоновой синхронизации можно использовать Планировщик заданий Windows.

Рекомендуемый вариант:

- отдельная задача Планировщика для Sin Streets;
- отдельная задача Планировщика для Nitro Rush;
- повтор каждые 5 минут;
- дополнительный триггер `При запуске компьютера`;
- если задача уже выполняется — `Не запускать новый экземпляр`.

Для запуска в фоне используется `sync_google_sheets_silent.bat` или прямой запуск Python через `pythonw.exe`.

## Важно

Скрипты работают локально. Пока компьютер выключен, синхронизация не выполняется. После включения ПК Планировщик Windows может автоматически продолжить обновление, если настроен соответствующий триггер.
