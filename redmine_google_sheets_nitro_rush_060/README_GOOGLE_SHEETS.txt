REDMINE -> GOOGLE SHEETS
========================

УЖЕ НАСТРОЕНО
-------------
Google-таблица:
https://docs.google.com/spreadsheets/d/1xOdwyVtcpU4ZK8Z1wylRjT6ldJfUTtD-vBYh06_THLY/edit#gid=896698793

GOOGLE_SHEET_ID = "1xOdwyVtcpU4ZK8Z1wylRjT6ldJfUTtD-vBYh06_THLY"
GOOGLE_WORKSHEET_GID = 896698793

Redmine API key уже прописан в redmine_client.py.
Проект и версия сейчас остаются как в исходном скрипте:
PROJECT_NAME = "Sin Streets"
VERSION_FILTER = "0.5.1 (пуши, улучшения, награды)"

ПЕРВЫЙ ЗАПУСК
-------------
1. Установи зависимости:
   pip install -r requirements.txt

2. В Google Cloud:
   - создай проект;
   - включи Google Sheets API и Google Drive API;
   - создай Service Account;
   - создай JSON key;
   - скачанный JSON положи рядом со скриптом и назови service_account.json.

3. Открой service_account.json и найди поле client_email.
   В Google-таблице нажми "Поделиться" и добавь этот email с правами Редактора.

4. Запусти start_google_sheets.bat.

ЧТО ДЕЛАЕТ СИНХРОНИЗАЦИЯ
------------------------
Скрипт открывает именно вкладку с gid=896698793 и при каждом запуске заново
получает актуальные задачи из Redmine и обновляет колонки A:G:
Название | Ссылка | Статус | Комментарий | Версия | Критичность для релиза | Назначена

Колонки H и дальше скрипт не очищает.
Новые задачи появляются в таблице, а изменения в существующих задачах
(статус, исполнитель, комментарий и т.д.) подтягиваются при следующем запуске.

АВТОМАТИЧЕСКИЙ ЗАПУСК
---------------------
Если нужна синхронизация без ручного запуска, добавь start_google_sheets.bat
в Планировщик заданий Windows, например с запуском каждые 5 минут.


ОБНОВЛЕНИЕ: КОДИРОВКА И АВТОСИНХРОНИЗАЦИЯ
------------------------------------------
start_google_sheets.bat — ручной запуск с нормальным UTF-8 выводом.
sync_google_sheets_silent.bat — запуск без паузы, предназначен для Планировщика заданий Windows.
Лог автоматических запусков сохраняется в sync.log рядом со скриптом.

Рекомендуемый интервал Планировщика: каждые 5 минут.
В Планировщике запускай sync_google_sheets_silent.bat, а не start_google_sheets.bat.
