REDMINE → GOOGLE SHEETS — NITRO RUSH 0.6.0

Назначение
----------
Отдельная локальная синхронизация для проекта Nitro Rush.

Настройки:
- Проект Redmine: Nitro Rush
- Версии: все версии, в названии которых встречается 0.6.0
- Трекер: только "Ошибка"
- Google Sheets:
  https://docs.google.com/spreadsheets/d/1PBEBm5SY_D92_nA7FCsTlK02A88ZFsETY2xbbvp8U9s/edit?gid=0#gid=0
- Вкладка: gid=0

Сохраняется текущая логика:
- новые задачи добавляются;
- существующие задачи перечитываются из Redmine и обновляются;
- обновляются статус, приоритет, назначенный, версия, название, комментарий;
- статусы и приоритеты имеют цветовую маркировку;
- активные задачи сортируются по приоритету;
- Бэклог идёт перед решёнными;
- Решена/закрытые уходят в самый низ;
- в таблицу попадают только задачи с трекером "Ошибка".

Первый запуск
-------------
1. Положите service_account.json рядом со скриптом.
2. Убедитесь, что сервисный аккаунт добавлен в целевую Google-таблицу как Редактор.
3. Установите зависимости:
   pip install -r requirements.txt
4. Запустите:
   python -X utf8 redmine_export_google_sheets.py

Автоматизация
-------------
Для фоновой синхронизации создайте отдельную задачу в Планировщике Windows,
например "Nitro Rush Google Sheets Sync", и запускайте этот файл из отдельной папки.

Важно: не используйте ту же задачу Планировщика, что и для Sin Streets,
если обе синхронизации должны работать параллельно.
